# El Pata Negra ESP32

Line follower competitivo basado en ESP32-S3.

## Hardware
- ESP32-S3
- QTR 8 sensores
- Driver de motores PWM
- Motores DC

## Software
- PlatformIO
- Arduino Framework
- C++

## Características
- Control PID
- Calibración automática
- PWM a 31.25 kHz
- Código modularizado con .h/.cpp
